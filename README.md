# Polyomino Block Blast

8×8 보드에 폴리오미노 블록을 놓아 줄을 지우는 퍼즐 게임입니다. 점수를 올리며 **증강(로그라이크 강화)**, **아이템**, **특수 블록**을 모아 점수를 극대화합니다.

React + TypeScript + Vite로 작성되었습니다.

## 게임 규칙

- **보드**: 8×8 격자.
- **트레이**: 항상 3개의 블록이 주어집니다. 3개를 모두 사용하면 새 3개가 채워집니다.
  - 새 트레이는 **현재 보드에서 3개를 모두 놓을 수 있도록(풀이 가능하도록)** 보장하여 제공됩니다.
- **블록**: 기본 덱은 **테트로미노(4칸 블록: O/I/L/J/S/Z/T) 19종**뿐입니다. 그 외의 모든 블록(단일/2·3칸, 5·6·9칸, **대각선**, **거대 블록 최대 4×4=16칸**)은 **특수 블록처럼 플레이로 해금**한 뒤 [덱 구성](#특수-블록-special-block)에서 넣을 수 있습니다.
- **배치**: 트레이의 블록을 선택한 뒤 보드 칸을 클릭해 놓습니다. 포인터 위치에서 **한 칸 이내**의 가장 가까운 유효 위치로 스냅됩니다. 미리보기 자리에 놓을 때 얻는 점수가 현재 점수 옆에 `+n`으로 표시됩니다.
- **줄 제거**: 가로 행 또는 세로 열이 가득 차면 해당 줄이 제거됩니다. 행과 열을 동시에 채우면 한 번에 여러 줄이 사라집니다.
- **콤보**: 줄을 지울 때마다 콤보가 쌓여 콤보 점수가 커집니다. **줄을 한 번도 지우지 못한 채 트레이 3개를 모두 소진하면 콤보가 초기화**됩니다.
- **게임 오버**: 현재 트레이의 어떤 블록도 보드에 놓을 수 없으면 게임이 종료됩니다.
- **저장**: 진행 상황이 자동 저장되어 "이어하기"가 가능하며, 최고 점수가 기록됩니다.

## 점수 계산

블록을 놓을 때마다 아래 항목들이 합산됩니다. (`Lv`는 해당 증강 레벨, 기본 0)

| 항목 | 계산식 | 설명 |
|---|---|---|
| 배치 점수 | `(블록 칸 수 + 추가 칸) × (1 + Lv×10%)` | 항상 획득. 추가 칸은 확산/채움으로 생긴 칸 |
| 제거 점수 | `지운 줄 수 × 20 × (1 + Lv×10%)` | 줄 1개당 기본 20점 |
| 멀티라인 점수 | `(지운 줄 수 − 1) × (15 + Lv×10)` | 한 번에 2줄 이상 지울 때 |
| 콤보 점수 | `지운 줄 수 × 콤보 × (5 + Lv×5)` | 콤보가 쌓일수록 증가 |
| 올클리어 점수 | `보드를 비우면 Lv×50` | 보드를 완전히 비웠을 때 |

칸/균열 보너스, 콤보 가속(전체 배율), 특수 블록 점수(고스트/에코/황금/폭탄/강화)는 위에 추가로 합산됩니다.

## 증강 (Augment)

점수가 일정 목표에 도달하면 **3종 중 1개를 선택**해 강화합니다. 각 증강은 **타입(카테고리)** 을 가집니다.

- **다음 목표 점수**: `직전 선택 점수 + 50 + (직전 선택 점수의 10%)`. 첫 증강은 50점에서 등장합니다.
- 대부분 무한히 레벨업할 수 있고, **다시뽑기**만 최대 5레벨입니다.
- 증강을 **3번 선택하면 다음 선택 차례가 증강 대신 특수 블록 선택**으로 바뀝니다(증강 3개 → 특수 블록 → 증강 3개 → …). → [특수 블록](#특수-블록-special-block)

상태 표기: ✅ 구현됨 · 🔜 예정(상태/트레이 솔버/아이템 시스템 연동 필요)

| 타입 | 증강 | 효과 | 상태 |
|---|---|---|---|
| 콤보형 | 콤보 | 콤보가 이어질수록 콤보 추가 점수를 얻는다 | ✅ |
| 콤보형 | 콤보 가속 | 콤보가 높을수록 획득 점수 배율이 증가한다 | ✅ |
| 콤보형 | 콤보 유지 | 콤보가 끊길 상황에서 일정 횟수 콤보를 유지한다(줄 제거 시 충전) | ✅ |
| 콤보형 | 콤보 보정 | 트레이에 콤보를 이어가기 쉬운 작은 블록이 나올 확률이 증가한다 | ✅ |
| 줄 제거형 | 제거 | 줄 제거 점수가 곱연산으로 증가한다 | ✅ |
| 줄 제거형 | 칸 제거 보너스 | 제거된 칸 수에 비례해 추가 점수를 얻는다(합연산) | ✅ |
| 줄 제거형 | 연쇄 제거 | 줄 제거 시 일정 확률로 근처 줄을 추가 제거한다 | ✅ |
| 줄 제거형 | 균열 제거 | 제거된 줄과 인접한 블록 수에 비례해 추가 점수를 얻는다 | ✅ |
| 멀티라인형 | 멀티라인 | 여러 줄을 동시에 제거하면 추가 점수를 얻는다 | ✅ |
| 멀티라인형 | 포화 | 보드 점유율이 높을수록 배치 점수가 증가한다 | ✅ |
| 멀티라인형 | 과열 | 줄 제거 없이 배치할수록 다음 제거 점수가 증가한다 | ✅ |
| 안정 배치형 | 배치 | 배치 점수가 곱연산으로 증가한다 | ✅ |
| 안정 배치형 | 칸 배치 보너스 | 배치한 칸 수에 비례해 추가 점수를 얻는다(합연산) | ✅ |
| 안정 배치형 | 확산 | 블록 배치 시 일정 확률로 주변 빈칸을 추가로 채운다 | ✅ |
| 안정 배치형 | 올 클리어 | 보드를 전부 비우면 큰 추가 점수를 얻는다 | ✅ |
| 아이템형 | 다시뽑기 | 다시뽑기 아이템을 강화한다(최대 5레벨, 아래 참조) | ✅ |
| 아이템형 | 아이템 조건 약화 | 아이템 획득에 필요한 콤보 간격이 감소한다 | ✅ |
| 아이템형 | 보급 점수 | 아이템을 획득할 때마다 추가 점수를 얻는다 | ✅ |
| 아이템형 | 사용 보너스 | 아이템을 사용할 때마다 추가 점수를 얻는다 | ✅ |
| 아이템형 | 아이템 연계 | 아이템 사용 후 다음 배치 점수가 증가한다 | ✅ |
| 기타 | 가속 | 다음 증강 획득에 필요한 점수가 레벨당 10% 감소한다(최대 90%) | ✅ |

### 다시뽑기 강화 레벨
| 레벨 | 효과 |
|---|---|
| 1 | 바꿀 블록을 **직접 선택** |
| 2 | 바꿀 블록 **2개** |
| 3 | 바꿀 블록 **3개** |
| 4 | 새 블록을 **후보 3개 중 선택** |
| 5 | 새 블록을 **덱에서 직접 선택** |

## 아이템 (Item)

- **획득**: **콤보가 10의 배수가 될 때마다**(10·20·30…) 무작위 아이템을 1개 받습니다. 아이템 칸은 **최대 3개**이며, 칸이 가득 차면 초과분은 사라집니다. (콤보가 0으로 리셋된 뒤 다시 10에 도달하면 또 받습니다.)
- 종류는 3가지입니다.

| 아이템 | 효과 |
|---|---|
| **되돌리기** (undo) | 직전 한 수를 되돌립니다 (보드·점수·트레이·특수 마크까지 복원). **더 둘 수 없어 게임오버가 될 상황이면 자동으로 사용**되어 한 번 더 기회를 줍니다. |
| **리롤** (reroll) | 트레이 블록을 새로 뽑습니다. **다시뽑기 증강**이 있으면 바꿀 블록과 새 블록을 직접 고르는 모달이 열립니다. |
| **중력** (gravity) | 보드의 모든 블록을 **한 칸씩 차례로 바닥으로 떨어뜨립니다**. 떨어지다 줄이 가득 차면 제거되고, 그 위 블록이 계속 내려오는 **연쇄**가 일어납니다(특수 블록 효과도 함께 이동). |

## 특수 블록 (Special Block)

증강을 3번 선택하고 나면 **다음 선택 차례가 증강 대신 블록 해금**으로 바뀝니다. **3개 중 1개를 선택**하는데, 후보는 **특수 효과 블록**과 **아직 해금하지 않은 기본 블록(테트로미노 외 모양·대각선·거대 블록)** 이 섞여 나옵니다. 선택한 블록은 현재 게임 덱에 바로 추가되고, 영구 해금되어 이후 덱 구성에서도 사용할 수 있습니다.

모든 특수 블록은 **일반 블록처럼 다양한 폴리오미노 모양**으로 나옵니다.

**덱 구성(들고 가기)**: 해금한 블록은 영구 저장됩니다. **시작 화면의 "덱 구성" 버튼**에서 다음 새 게임의 덱을 직접 구성합니다. 모달은 **왼쪽 "현재 덱" / 오른쪽 "가진 블록"** 두 패널로, **가진 블록을 클릭하면 덱에 추가**, **덱 블록을 클릭하면 한 개 제거**됩니다(중복 허용 → 등장 확률 가중).
- **기본 블록**: 테트로미노 + 해금한 일반 블록, **총 20개까지**(최소 1개).
- **특수 블록**: **최대 3개**.
- 구성은 저장되어 유지되며, "새 게임"을 시작하면 이 덱으로 플레이합니다.

| 특수 블록 | 효과 |
|---|---|
| **고스트** (ghost) | 이미 블록이 있는 칸 위에도 놓을 수 있습니다. 겹친 칸이 나중에 줄 제거로 사라지면 **칸당 +20점**. |
| **라인** (line) | 놓는 즉시 **각 칸이 속한 행과 열을 모두 제거**합니다. |
| **에코** (echo) | 설치 시 **보드에 쌓인 블록 수 × 5점**을 추가로 얻습니다. |
| **황금** (golden) | 황금 칸이 줄 제거에 포함되면 **그 칸 점수를 두 배**로 얻습니다. |
| **폭탄** (bomb) | 이 블록의 칸이 줄 제거로 사라질 때 **그 칸의 행과 열을 폭파**합니다(연쇄 가능, 폭파 칸당 +5점). |
| **채움** (fill) | 설치 시 **상하좌우 한 칸 이내의 빈 칸을 채웁니다**(채운 만큼 배치 점수 가산, 줄이 완성되면 함께 제거). |
| **강화** (boost) | 보드에 놓여 있는 동안 **획득 점수가 칸당 +5%** 증가합니다(여러 개·여러 칸이면 합산). 칸이 줄 제거로 사라지면 효과도 사라집니다. |

## 실행 방법

```bash
npm install        # 의존성 설치

npm run dev        # 개발 서버 (http://127.0.0.1:5173)
npm run build      # 타입체크 + 프로덕션 빌드
npm run preview    # 빌드 결과 미리보기
npm test           # 테스트 실행 (Vitest)
npm run typecheck  # 타입 검사만
```

### 기술 스택
- **React 19** + **TypeScript** + **Vite**
- 테스트: **Vitest**
- 아이콘: **lucide-react**
- 상태 저장: 브라우저 **localStorage**

### 프로젝트 구조
```
src/
├─ App.tsx              # 게임 메인 (상태·흐름 오케스트레이션)
├─ components/          # UI 컴포넌트 (보드, 트레이, 각종 모달 등)
├─ features/            # 게임 기믹 (증강, 아이템, 특수 블록, 배치 해석)
├─ hooks/               # 커스텀 훅 (블록 선택, 오디오, 콤보 효과 등)
├─ utils/               # 순수 로직 (배치, 보드 연산, 트레이 솔버)
├─ constants/           # 블록 카탈로그·설정값
└─ types.ts             # 공용 타입 정의
```
